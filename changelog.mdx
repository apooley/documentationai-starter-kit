<Update label="2026-10-06" description="v2.0.0" tags={["feature", "improvement"]} id="v2-0-0">

## New Features

- **Assistant cloning**: Clone an existing assistant to any workspace within the same tenant, with an option to copy its attached playbook
- **Playbook duplication**: Duplicate a playbook to quickly create variants for A/B testing or iteration
- **Close chat after goals met**: New playbook toggle to automatically close conversations once the playbook's goals are achieved
- **Manual ADF resend**: Operators can manually trigger an ADF (Structured XML) resend from the conversation detail page, rebuilding from current conversation state
- **ADF on qualification toggle**: New settings toggle to control whether ADF sends automatically on lead qualification (default: on)
- **Quiet-window ADF delay**: The system now waits for conversation silence after provisional qualification before summarizing and sending the ADF
- **Deferred ADF sends**: ADF sales sends are deferred until the lead has an email or phone number on file
- **Native Meta DM support**: Full DM (direct message) support for Facebook and Instagram via the Native Meta Connector, including OAuth connect, inbound processing, persisted history, and compliance callbacks
- **Global workspace switcher**: A unified workspace switcher in the sidebar replaces page-level selectors across all scoped pages, with client-side persistence across sessions
- **Tracking Configuration UI**: New Tracking tab in Chat Widget settings to enable tracking and manage event mappings/outcomes
- **chat_started event**: New `autoch.at.chat_started.v1` event emitted when a user sends their first real message in the widget
- **Product link validation**: The AI now requires `search_products` evidence before sending product links in chat and fails closed if no matching product is found

## Improvements

- **Product feed sync retry**: Failed feed syncs now retry at 1h, 3h, 8h, then every 24h, with email notification to tenant admins once per failure streak
- **Dynamics memo truncation**: Conversations exceeding the Dynamics 10,000 character Memo limit now use prefer-recent truncation, keeping the newest turns
- **Contact data persistence**: Phone and email data typed in the chat widget is now persisted even when PII redaction is off, preventing the AI from re-asking for contact info
- **Orphan profile cleanup**: Orphan Default Profiles from initial setup are automatically cleaned up

## Bug Fixes

- Fixed ADF notification log insertion that silently failed after send
- Fixed inactivity ADF logging and UTC timestamp skew
- Fixed workspace switcher dropdown appearing behind the sidebar
- Fixed conversation summary generation for immediate and deferred qualification paths

</Update>

## Upgrade Instructions

Follow these steps to upgrade your Autoch.at integration safely.

<Callout kind="alert">
Before upgrading, back up your configuration and test in staging. Review breaking changes in each release.
</Callout>

<Steps>
  <Step title="Check Compatibility" icon="check-circle">

Review your current version against the table below.

| Current Version | Minimum Node.js | Upgrade Path |
|-----------------|-----------------|--------------|
| `<1.0.0`       | `18+`          | Full reinstall |
| `1.0.x`        | `18+`          | `npm update` |
| `1.1.x`        | `20+`          | Patch migration |

  </Step>
  <Step title="Update SDK" icon="download">
    <Tabs>
      <Tab title="npm" icon="package">
````bash
npm install @autoch.at/sdk@latest
````
      </Tab>
      <Tab title="yarn" icon="package">
````bash
yarn add @autoch.at/sdk@latest
````
      </Tab>
    </Tabs>
  </Step>
  <Step title="Migrate Config" icon="settings">

Update your `{API_KEY}` and webhook endpoints.

````javascript
// Old config
const config = {
  apiKey: 'YOUR_API_KEY',
  webhook: 'https://your-webhook-url.com/old'
};

// New config (v1.2.0+)
const config = {
  apiKey: 'YOUR_API_KEY',
  webhook: 'https://your-webhook-url.com/webhook',
  piiRedact: true
};
````

  </Step>
  <Step title="Test & Deploy" icon="rocket">
    Run integration tests against `https://api.example.com/v1/conversations`.
  </Step>
</Steps>
