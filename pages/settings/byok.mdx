title: Bring Your Own Key (BYOK)
description: Use your own OpenAI API key for your AI assistants so you pay OpenAI directly. Buy the one-time add-on, wait for approval, then add, test or remove your key.
---

**BYOK** lets you use your own OpenAI account's API key for your assistants, so you can control and see your AI costs directly with the provider.

Find it in the left menu under **Settings** > **BYOK**. The item only shows if BYOK is available on your account. If you can't see it, ask support.

## How it works

<Steps>
  <Step title="Buy the add-on">
    On the BYOK page, find **AI Keys (OpenAI)** and click **Purchase Add-On**. It's a one-time price, shown as "(one-time)".
  </Step>
  <Step title="Wait for approval">
    After purchase it shows **Purchased (Pending Approval)** and "Waiting for administrator approval". An Autoch.at administrator has to switch it on before you can add a key.
  </Step>
  <Step title="Add your key">
    Once it shows **Enabled**, a new **AI API Keys** section appears with "No API key set". Click **Add Key**, paste your OpenAI API key into the box and click **Save**.
  </Step>
  <Step title="Test it">
    Click **Test**. It makes a small test call to check the key works. If it fails, check the key's permissions and that your OpenAI account is active and paid up.
  </Step>
</Steps>

## Manage your key

Once saved, the card reads "API key configured":

- **Test** checks the key still works.
- **Update** replaces it with a new key.
- **Delete** removes it permanently. The platform then goes back to using Autoch.at's own keys. Have a backup key ready if you need one.

## Keep it safe

- Keys are stored encrypted. The page only tells you whether a key is set; it never shows the key itself.
- Never share your key or put it in emails or documents.
- Use a separate key for Autoch.at, and rotate it regularly.
- If you think a key has leaked, delete it in OpenAI's dashboard, then add a new one here with **Update**.

<Callout kind="info">
With BYOK, your AI charges appear on your OpenAI account, so check OpenAI's dashboard for usage and cost.
</Callout>
