The **Widget Playground** is a safe test space. You chat with your assistant exactly as a website visitor would, and you can adjust how the widget looks, all without touching your live website.

Open **Conversations → Widget Playground** in the sidebar.

<Callout kind="info">
Changes you make here are temporary and only affect the preview. To change your real widget, go to [Settings → Chat Widget](/pages/settings/chat-widget).
</Callout>

## Start a test

<Steps>
  <Step title="Open the Playground">
    Click **Conversations → Widget Playground**.
  </Step>
  <Step title="Generate a token (first time only)">
    If the preview says "Generate a widget token to see the preview," click **Generate Token**. This lets the preview talk to your account.
  </Step>
  <Step title="Pick an assistant">
    On the right, under **Chat with assistant**, choose which assistant to test. **Default (chat default)** uses your default chat assistant. Switching assistants clears the current chat.
  </Step>
  <Step title="Send a message">
    The widget is already open in the **Live Preview**. Type a message and press Enter. The assistant replies just as it would for a real customer, with a typing indicator while it thinks.
  </Step>
  <Step title="Start over when you want">
    Click **Start New Session** to wipe the chat and begin fresh.
  </Step>
</Steps>

<Callout kind="alert">
Playground chats are temporary. They are cleaned up automatically after a short time (about 15 minutes), so don't rely on them as a record.
</Callout>

## Change how the widget looks

On the left, **Customization** has:

| Setting | What it does |
|---|---|
| **Primary Color** | The color of the launcher button and chat header. Pick a color or type a hex code such as `#3B82F6`. |
| **Company Name** | The name shown in the widget header. |
| **Launcher Style** | **Floating circle**, **Bottom-right bar** or **Centre-left bar**. |
| **Launcher Content** | **Icon only**, **Text only** or **Icon + text**. |
| **Launcher Text** | The words on the launcher, for example "Chat with us". |
| **Position** | **Bottom Right** or **Bottom Left**. |
| **Greeting Message** | The first message visitors see, for example "Hi! How can I help you today?" |

The preview updates as you type.

## Copy the embed code

When you like what you see, scroll to **Embed Code** and click **Copy Code**. Paste it just before the closing `</body>` tag on every page where you want the widget to appear. If you don't see any code yet, click **Generate Token**.

To make your choices permanent for your live widget, also save them in [Settings → Chat Widget](/pages/settings/chat-widget).

## What to test before going live

- **Common questions**: does the AI answer your most frequent questions correctly?
- **Edge cases**: what happens when someone asks something it doesn't know?
- **Playbooks**: do they start at the right moment? See [AI Playbooks](/pages/ai-config/playbooks).
- **Handoffs**: does the AI pass the chat on when it should? See [Routing & Handoffs](/pages/ai-config/routing-handoffs). If you use [warm transfer](/pages/ai-config/warm-transfer), you'll see "Connecting you with *name*…" in the chat when it hands over.
- **Branding**: are the color, name and greeting right?

<Callout kind="tip">
Try to "break" your assistant before customers do. Ask confusing questions, leave out details, and steer it off-topic.
</Callout>

## If a message fails to send

If a message can't be delivered (for example, you lost your internet connection), it turns red with a short reason. Click **Retry** to send it again.

## Training mode commands

If the assistant has **Training mode (web chat)** switched on (in **AI Assistant → Assistants → Edit → Channels & Routing**), you'll see "Training mode enabled for this assistant" and you can type these commands in the chat:

| Command | What it does |
|---|---|
| `/clear` | Resets the widget session completely: clears the stored contact (name and email), the conversation and any draft, and restarts name and email collection. It doesn't send anything to the AI. |
| `/flag-good` | Marks the conversation as a good training example. |
| `/flag-bad` | Marks it as a bad training example. |

Flagged conversations can be filtered under **Training review** in [Conversations](/pages/conversations/conversations). See [Training Review](/pages/ai-config/training-review).

<Callout kind="tip">
Use `/clear` to pretend you're a brand-new visitor, for example to test the name and email questions again.
</Callout>
